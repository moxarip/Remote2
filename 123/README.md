## 🚀 الميزات المتضمنة في هذا البناء:
1. **🔔 إرسال إشعار فوري من الآدمن للهوست (Admin Alert Notification):**
   - يظهر كإشعار عائم بأعلى الشاشة (*Heads-up Notification*) بأولوية قصوى واهتزاز وصوت.
   - يختفي ويُلغى تلقائياً فور النقر عليه أو سحبه **دون أن يفتح التطبيق أو ينقل المستخدم لأي شاشة** عبر `DismissNotificationReceiver`.
   - إمكانية الإرسال من شاشة الآدمن عبر زر الجرس العلوي أو زر لوحة الإجراءات السريعة.
2. **💾 تحويل الهاتف إلى هوست تخزين سحابي شخصي (Personal Storage Node):**
   - تحديد وتفويض مجلدات كاملة عبر نظام Android SAF (`ACTION_OPEN_DOCUMENT_TREE`) أو ملفات منفردة (`ACTION_OPEN_DOCUMENT`).
   - حفظ الصلاحيات المستمرة `FLAG_GRANT_READ_URI_PERMISSION`.
3. **📁 تصفح محتويات وتفرعات مجلدات الهوست عن بُعد عبر الآدمن:**
   - فحص وتصفح شجري ذكي يشمل كافة التفرعات والمجلدات (`Android/media`، التنزيلات، المستندات).
   - حماية المجلدات المقيدة من النظام وتوضيح حالتها في الواجهة.
4. **⚡ نقل واستعراض الملفات عند الطلب (On-Demand File Streaming):**
   - استعراض مباشر للصور والمستندات عبر خادم وسائط محلي مشفر ومباشر.
   - تنزيل الملفات إلى جهاز الآدمن عند الحاجة دون رفع تلقائي شامل.
